Recipe Page - Frontend Mentor Challenge
This is a solution to the Recipe Page challenge on Frontend Mentor. This project focuses on creating a pixel-perfect, responsive layout using modern CSS techniques.

🚀 The Approach
My approach to this project was centered around technical quality and UI/UX consistency, following these core principles:

1. Structure & Semantics
HTML5 Mastery: Used semantic tags like <header>, <main>, and <section> to ensure accessibility and SEO optimization.

Responsive Architecture: Implemented a mobile-first approach, starting from 375px and scaling up to a refined 1440px desktop view.

2. Styling Strategy (CSS)
Design Tokens: Leveraged CSS Variables (:root) to manage the color palette (Stone, Brown, Rose scales) for easy customization and visual consistency.

Advanced Selectors: Used pseudo-elements like ::marker to customize list styles specifically for each section, matching the design's unique color requirements.

Pixel-Perfect Precision:

Fine-tuned the nutrition table using Flexbox to ensure vertical alignment of values.

Managed content flow using max-width and padding to ensure readability across all devices.

3. Performance & Typography
Local Font Optimization: Instead of relying on external CDNs, I implemented @font-face for "Outfit" and "Young Serif" to reduce layout shift (CLS) and ensure the design remains intact offline.

🛠️ Built With
Semantic HTML5 markup

Custom CSS Properties (Variables)

Flexbox for layout and alignment

Mobile-first workflow

Local Font Declarations

📈 Key Features Implemented
Responsiveness: Fluid transition between mobile and desktop layouts.

Interactive Tables: Clean, bordered nutrition data for high scannability.

Custom Bullet Points: Section-specific colors for unordered and ordered lists.

💡 What I Learned
During this build, I refined my skills in:

Managing complex list styles using CSS markers.

Balancing container widths to maintain alignment between text, horizontal rules (hr), and tables.
